# PeopleFlow – Employee Management System

A web-based Employee Management System designed to manage employee information through a simple and user-friendly interface.

## 🌐 Live Demo

**[View Live Project](https://mansichauhan7088.github.io/peopleflow-employee-management/)**

## 📌 Project Overview

PeopleFlow is a frontend web application created to provide an organized interface for managing employee-related information.

The project focuses on a clean user interface, structured data presentation, and easy navigation.

## ✨ Features

* Employee management interface
* Clean and responsive user interface
* Employee information display
* Easy navigation between sections
* Interactive frontend elements
* Simple and user-friendly design

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and dynamic behavior
* **Git & GitHub** – Version control and project hosting
* **GitHub Pages** – Live deployment

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Mansichauhan7088/peopleflow-employee-management.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
