# PeopleFlow — Employee Management Dashboard

A responsive employee management dashboard built using HTML, CSS, and JavaScript.

## 🚀 Features

- Employee management dashboard
- Add new employees
- Edit employee information
- Delete employees
- Search employees
- Filter employees by department
- Sort employees
- Employee details panel
- Responsive design
- Data persistence using LocalStorage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📸 Project Preview

PeopleFlow provides a clean and responsive interface for managing employee information.

## 💡 What I Learned

Through this project, I practiced:

- DOM manipulation
- JavaScript event handling
- CRUD operations
- Form handling
- LocalStorage
- Search and filtering logic
- Responsive UI development
